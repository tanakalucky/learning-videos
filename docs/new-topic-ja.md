# 次のテーマを作る

1. 対象読者、理解してほしい一点、長さ（60〜90秒）、音声の有無を決める。
2. 最新の一次資料を読み、URL・確認日・主張との対応を `docs/sources-テーマ.md` に残す。秘密情報・実サービス環境は使わない。
3. `topics/iap` を `topics/新テーマ識別子` にコピー。`DURATION` と `SCENES` を編集し、シーンの描画をテーマに合わせる。共通部品は `engine` に保つ。
4. 一字幕を最大2行にし、読む時間を確保。認証と認可など混同しやすい概念、図の省略、前提を明示する。
5. `python3 render.py --topic 新テーマ --time 秒` で各場面を確認。`--topic 新テーマ` で本編出力。
6. そのテーマに合う基本チェックとMP4検証を追加・調整する。既存check/inspectは第1作の78秒・2340フレームを検証するため、数値を更新する。
7. プレビューHTMLの題名、パス、章リストを更新。各カット前後、最長字幕、最終フレームを確認。MP4を実際にデコードし、字幕・欠け・流れ・長さを点検。
8. 台本、出典、QA結果、ソースアーカイブ、MP4をまとめる。Gitに秘密・生成キャッシュ・動画フレームを追加しない。公開先未確認ならpushしない。

大きな汎用化はせず、次の作品で必要になった共通部品だけを追加する。
