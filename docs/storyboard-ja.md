# IAP 台本・絵コンテ

78秒 / 日本語焼き込み字幕 / 音声なし。矢印は論理順序を表す。

## 00–09秒：IAPは、アプリの入口を守る

画面：利用者→IAP→保護対象アプリ。入口の役割を提示。

字幕：

URLを知っていても、誰でも入れるわけではありません。
IAPは「誰がアクセスできるか」を入口で確認します。

## 09–20秒：まず「あなたは誰？」

画面：利用者からログインへ、本人確認完了までを順に強調。

字幕：

未ログインなら、ブラウザをログイン画面へ案内します。
認証は、利用者が誰なのかを確かめることです。

## 20–31秒：次に「このアプリへ入れる？」

画面：認証済みの人と対象リソースのアクセス権をIAPが照合。

字幕：

本人確認のあと、IAPがIAMポリシーを確認します。
ログインできることと、アプリへ入れることは別です。

## 31–43秒：許可された人は、アプリへ

画面：緑の矢印がIAPを通過し、アプリへ到達。

字幕：

IAPのアクセス権があるAさんは、アプリへ進めます。
ユーザーやグループに、対象リソースへの権限を設定します。

## 43–54秒：許可がなければ、入口で拒否

画面：赤の矢印はIAPまで。拒否表示、アプリへの矢印は描かない。

字幕：

Bさんも本人確認は済んでいますが、アクセス権がありません。
IAPが拒否し、この要求はアプリへ届きません。

## 54–66秒：入れたあとも、権限はある

画面：IAP通過後、アプリ内の閲覧・編集・承認を別のルールとして表示。

字幕：

IAPを通過しても、すべての操作ができるわけではありません。
「閲覧・編集・承認」などは、アプリ側で制御します。

## 66–78秒：覚えるのは、この3つ

画面：3概念を横並び。Cloud Runへ直接IAPを設定できる注記。

字幕：

認証は「誰か」、IAPの認可は「入れるか」。
アプリ内の権限は「何ができるか」です。
